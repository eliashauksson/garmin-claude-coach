# Training Principles
Basis: Training for the Uphill Athlete (House/Johnston/Jornet). (d)=app default, tunable. Athlete data comes from profile + Garmin. Athlete approves plans before push; always justify with rule refs.

## GENERAL

### Core
- Aerobic base first; intensity only sharpens an existing base, never replaces it.
- Consistency > single sessions; prefer the option that keeps athlete training next week.
- Conservative build always. When unsure between two loads, pick the lower: undertraining costs little, injury/overtraining costs weeks.
- Strength training is a year-round core component for all goals incl. long endurance; never drop below maintenance (1×/wk).
- Adaptation happens in recovery; individualize to own thresholds/history/response.
- Plan load in time per zone, not distance.

### Zones (HR, threshold-based, not %HRmax)
AeT = top of Z2, near-resting lactate, nasal breathing/full sentences possible. LT ≈ max steady 30–60 min effort.
- Rec: <Z1
- Z1: ≤ AeT−10%
- Z2: AeT−10% → AeT
- Z3: AeT → just below LT
- Z4: ≈LT
- Z5: >LT
Use tested values > Garmin estimates (flag estimates). Untested AeT: assume LT_HR−15–20% (err easy). Recalc zones on every new test.

### ADS (key diagnostic)
gap = (LT_HR − AeT_HR)/LT_HR
- gap >10% = ADS: ~95–100% Rec/Z1–Z2; no Z3–Z5 sessions; allowed: hill sprints, strides, general/max strength. Retest AeT every 4–6 wk (d). Correction takes months; explain to athlete why intensity is withheld.
- gap ≤10%: add Z3→Z4→Z5 progressively; Z1–Z2 stays majority.

### Intensity distribution
- Base (non-ADS): 80–90% Z1–Z2.
- Specific: Z1–Z2 still majority; ≤2 hard sessions/wk (d), never consecutive days, done fresh.
- Easy must stay easy; no Z3 drift on Z1–Z2 days.

### Load & recovery
- Weekly increase ≤10% from last build week (d); ≤15–20% only if <5 h/wk or returning to recently held volume. Year-over-year ≤~10%.
- Recovery week: 3:1 build:recovery (d); 2:1 if older, high life stress, post-illness. Recovery wk = 50–70% volume, keep small intensity touch.
- Long session ≤30–35% weekly endurance time (d); ultra/expedition may use back-to-backs.
- Hard/long day → next day easy/rest/strength-only. ≥1 rest day/wk (d).
- Return after break: <1 wk → 80%; 1–3 wk → 50–70%, ramp 2–3 wk. Fever/below-neck illness → no training until resolved, then easy several days.

### Strength / ME
Sequence: general strength (transition/early base; high reps, core, single-leg, mobility) → max strength (base, 4–8 wk, 2×/wk, 3–5 reps heavy, long rest) → ME (late base→specific, 1–2×/wk, 6–10 wk progression; only after max strength + adequate base; e.g. weighted uphill carries, steep bounding, gym ME circuits).
Hill sprints: 6–10 × 8–10 s max, steep, 2–3 min full recovery; OK for ADS; can append to easy session.
Scheduling: strength on easy days; no max/ME within 48 h before key session/race; maintenance (1 short/wk) in taper and race-heavy phases.

### Periodization (plan backwards from A-goal)
- Transition 2–8 wk: recover, unstructured easy aerobic, general strength.
- Base 8–24 wk: build volume, max strength→ME, fix ADS; Z3 then Z4 only if not ADS.
- Specific 6–10 wk: mimic event (terrain, duration, intensity, fuel, gear); volume plateaus/slight drop.
- Taper 1–3 wk (longer for longer events): volume to ~40–60% by race week, keep short intensity touches.
Short on time → shorten base, never skip taper; tell athlete the tradeoff. A-goal full periodization; B-goal 3–5 d mini-taper; C-goal = training. Transition after A-goal.

### Testing
- AeT drift: 10–15 min warm-up + 60 min constant pace/power at est. AeT HR, flat/constant grade. Compare avg HR half 1 vs 2 (or pace drop at fixed HR). <3.5% → AeT higher, retest higher; 3.5–5% → accept; >5% → AeT lower. Every 4–8 wk in base (d 6).
- LT: 30 min solo all-out TT, avg HR last 20 min ≈ LT_HR. Every 8–12 wk or block start.
- Invalid if heat, altitude, illness, poor sleep, dehydration, fatigue → flag/reject. Test after rest/easy day.

### Monitoring
Fatigue flags (≥2 → reduce load): RHR ≥+5 bpm vs baseline 2+ d; HRV below normal range several d; poor sleep several nights; HR abnormally high or suppressed at easy pace / can't reach interval HR; easy feels hard, persistent heavy legs, low motivation; performance declining. Garmin readiness/body battery/training status = supporting only. Subjective feel overrides good metrics.
Actions:
- 1 bad day → swap to easy/rest, keep week structure.
- Multi-day flags → rest of week recovery, replan next week lower.
- Missed sessions: never stack/make up volume; move key session only if hard/easy spacing holds.
- Pain (not soreness; sharp/local/worsening) → stop provoking activity, pain-free low-impact substitute, recommend professional if >~1 wk.
- Life stress (work, military service, travel, exams, sleep) reduces capacity → lower load.

### Cross-training
Counts toward aerobic load by zone; not toward sport-specific volume; can't replace specific-period sport work.

### Conflict priority
health/injury > recovery > consistency > aerobic base > specificity > intensity

## RUNNING

### Specifics
- Tissues adapt slower than cardio → running volume more conservative; carry extra aerobic volume via cross-training.
- Downhill = high eccentric load, not free even at low HR; progress it.
- Steep terrain: HR over pace; Z1–Z2 hiking is valid.
- Prescribe time+zone; pace only as guidance on flat road.

### Progression
- Running time ≤10%/wk (d); new/returning from injury ≤5–10% with 2:1 blocks.
- Road: long run ≤30% weekly running time (d); marathon long run cap 2.5–3 h (d) — beyond that, road impact/recovery cost outweighs aerobic gain.
- Trail/ultra: no fixed cap; long sessions 3–6 h+ (d) as time on feet (run+hike, Z1–Z2), on race-like terrain. Prefer back-to-back long days over single extreme sessions. Longest single session rarely needs to exceed ~50–60% of expected race time (d). Build long-session duration ≤~30 min/wk (d) and always follow with an easy/rest day.
- New runners: 3–4 consistent easy runs/wk before any structured intensity.

### Sessions (dur | zone | notes)
- Recovery: 20–45 min | Rec–Z1 | day after hard/long
- Easy: 30–90 min | Z1–Z2 | bulk; hard cap AeT HR
- Long: 75 min+ | Z1–Z2 | practice fueling if >90 min; max duration by goal, see Progression
- Strides: 4–8 × 15–20 s ~mile pace, full rec, after easy run | OK for ADS
- Hill sprints: see Strength | OK for ADS
- Tempo: 20–40 min or 2–3 × 10–15 min | Z3 | non-ADS
- Threshold: e.g. 4–6 × 5–8 min, 1–2 min rec, 20–40 min total Z4 | non-ADS
- VO2max: 5–6 × 3 min equal rec, or 8–10 × 1 min | Z5 | specific only, sparse
- Hill repeats/uphill ME: 2–5 min steep or weighted hikes | Z3–Z4/local ME | trail/mountain
- Downhill conditioning: progressive | Z1–Z2 | trail/mountain, marathon
- Race pace: blocks in long run or intervals | specific period

### By period
- Transition: easy unstructured 3–4×/wk + general strength/mobility.
- Base: 3–6 runs/wk by history, ~all Z1–Z2; strides 1–2×/wk; hill sprints 1×/wk; weekly long run; max strength 2×/wk → ME late base. Non-ADS: 1 Z3/wk in 2nd half, then Z4.
- Specific (≤2 hard/wk; long run with race pace counts as 1; ME/strength 1–2×/wk continues):
  - 10K/HM: threshold + VO2max emphasis; 2 quality + long run.
  - Marathon: long run + race-pace blocks, threshold, high aerobic volume, race fueling practice.
  - Trail/ultra: vert-specific, uphill ME, downhill conditioning, back-to-backs, race gear/nutrition on terrain.
- Taper: 10K/HM 7–10 d; marathon/ultra 2–3 wk (d). Volume to 40–60% by race week, keep race-pace/stride touches, strength maintenance, no ME last 10 d.

### Multi-race events (same day or consecutive)
Train total demand: cumulative duration/fatigue, fueling between efforts, repeated warm-up/recovery. Main specific target = longest race. Include hard running on pre-fatigued legs (race pace late in long run).

### Monitoring
- Injury precursors: persistent local pain (shin, Achilles, plantar, knee, hip), gait change, pain worsening during run → act per Monitoring.
- Progress marker: easy pace at fixed HR improving → report.
- Flag shoes >600–800 km (d).
- Garmin running tolerance/LT/race predictions = supporting only.

## PLAN PROCEDURE
1. Assess: thresholds (tested/est.), AeT/LT gap, actual volume last 4–8 wk per sport/zone, consistency, recovery signals.
2. Classify: ADS y/n; current period from weeks to goal.
3. Weekly load: progress from actual (not planned) volume; place recovery weeks.
4. Distribute: zones per distribution; place long session, quality (if allowed), strength/ME, rest days; hard/easy; fit availability.
5. Each session: sport, duration, zone (HR primary, pace/power secondary), structure (WU/main/CD), 1-line purpose.
6. Explain week purpose, link to goal, rules triggered.
7. Validate: progression limits, recovery rhythm, ≤2 hard/wk, no consecutive hard, strength not adjacent to key sessions, priority order.
